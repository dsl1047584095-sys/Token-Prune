\# Token-Prune: 基于自适应令牌剪枝的高效视频动作检测优化



本项目针对基于 Vision Transformer (ViT) 的视频动作检测模型中存在的计算冗余问题，设计并实现了两种核心剪枝策略：信息冗余自适应剪枝 (IRTP) 与注意力引导自适应剪枝 (HAG)。在大幅降低计算量 (FLOPs) 的同时，最大程度保持了动作检测的准确率 (mAP)。



\---



\## 💡 核心改进动机与技术细节



\### 1. IRTP (Information Redundancy Adaptive Token Pruning) - 信息冗余自适应剪枝

\* \*\*研究动机：\*\* 传统的 Token 剪枝方法通常在所有视频片段（Clips）中采用固定的保留率（Keeping Rate）。然而，视频内容在时间轴上存在显著的多样性：高运动强度的片段（如奔跑、打斗）信息量大，盲目剪枝会导致关键动作特征丢失；而低运动强度或静止的片段（如静坐、背景）冗余度极高。

\* \*\*技术实现：\*\* \* 引入运动强度感知模块，通过计算相邻帧之间的特征残差或时空变化率，动态评估当前视频片段的信息冗余度。

&#x20; \* 根据冗余度评分，自适应调整每个 Clip 的 Token 保留率。针对高动态片段自动调高保留率，针对高冗余片段则激进剪枝，实现计算资源的智能分配。



\### 2. HAG (Hierarchical Attention-Guided Pruning) - 分层注意力引导机制

\* \*\*研究动机：\*\* Vision Transformer 在不同网络深度（Layers）所关注的特征语义层次不同。浅层网络主要捕获低层级的局部空间结构，此时若进行大规模剪枝极易破坏微小的动作边界；深层网络则形成全局语义特征，冗余度更高。

\* \*\*技术实现：\*\*

&#x20; \* 利用 Transformer 自注意力机制中的 Attention Matrix 作为天然的显著性度量工具，提取每个 Token 对 Class Token 或 RoI 特征的贡献度。

&#x20; \* 采用\*\*分层渐进式剪枝\*\*策略：在网络浅层保持较高的 Token 留存，确保空间几何细节完整输入；随着网络层级加深，根据注意力权重逐步剔除与动作区域无关的背景 Token，实现深层特征的高效提纯。
